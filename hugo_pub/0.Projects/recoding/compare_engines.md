# 엔진 비교 — Apple vs whisper.cpp

> [!abstract] 결론
> **속도·무환각은 Apple, 고유명사·문장부호·대화체는 whisper.** whisper는 이 머신에서 **10~15배 느리고**, 진료 대화 녹음에서 **환각(반복 + "다음 영상에서 만나요")** 이 실제로 나왔다. 기본 엔진은 Apple 유지, **고유명사·대화 구간이 중요한 녹음만 whisper로 전환**하는 게 합리적이다.

측정 환경: macOS 26.6.2 / M-series 32GB / whisper.cpp 1.7.x (Metal, `MTL=1` 확인), `ggml-large-v3-turbo.bin` (1.5GB)
대상: 이미 처리된 노트 4개(총 30분 11초). Apple 전사문은 `result/*.md`에서, whisper는 같은 원본을 재전사.

## 2. 사례 A — 고유명사: whisper 압승

`건강보험확인`(51초, 기기 이름·도메인이 섞인 일상 메모)

| 발화 추정 | Apple | whisper |
|---|---|---|
| 건강보험료 **납입확인서** | 건강보험료**압의 확인서** | 건강보험료 **납입확인서** ✅ |
| 내 **갤럭시폰**이랑 **맥북 프로, 맥미니 3개**를 연결 | 내 **갤럭스폰이랑 에포 프로 맥민이 세계**를 연결 ❌ | 내 **갤럭시폰이랑 맥북 프로, 맥미니 3개**를 연결 ✅ |
| **브랜드 네임**을 만들었어 | 브랜드 **내용**을 만들었어 ❌ | **브랜드 네임**을 만들었어 ✅ |
| 이음돌.링크 도메인 | 이음돌 **점**링크 도메인 | 이음돌.링크 도메인 ✅ |

> [!tip] Apple의 실패 패턴
> Apple은 문장을 **하나의 긴 어절 덩어리**로 내보내면서 제품명·숫자를 뭉갠다("에포 프로 맥민이 세계" = "맥북 프로, 맥미니 3개"). whisper는 문장부호와 함께 **개체명을 분리**해 낸다.

## 3. 사례 B — 대화체: whisper 우세, 단 환각 동반

`허리디스크진료`(12:35, 의사-환자 대화)

**whisper** — 발화가 줄바꿈으로 분리되고 대화 흐름이 읽힌다:
```
지금 생활하는데 불편하신 점이 뭔가요?
- 막 꼬바제 찍어보는 건.
아파요? 힘이 없어?
- 근절부터 발목이 땡기고 아프면서
다리, 몸치까지 올라옵니다.
일어나봐요.
이렇게 걸어봐.
...
이거는 뼈 세멘트를 떼웠어요 여기다가
하나는 여기 신경구멍이 맺혔고
```

**Apple** — 한 덩어리로 붙고 발화 구분이 사라지며 일부 누락(문자 1.34배 차이 = Apple이 25% 적게 담음):
```
안 생겨니. 한 지금 생활하는 게 제일 불편하신 점이 뭔가요? 한 일주 전부터 발목이리 막 뽑아져…
그래서 읽어보니까 요거는 뼈 뼈세 멘트를 때웠어요 여기다가… 뼈가 두 군데가 안 좋네 하나는 여기 신경구멍이 맥혔고
```

> [!warning] whisper의 대가 — 환각
> 같은 파일에서 **12줄이 중복**됐고, 그중 하나는 whisper 특유의 학습데이터 잔재다.
> ```
> 5회  네.
> 4회  - 한쪽이 안 나는데? - 한쪽이 안 나는데?
> 2회  다음 영상에서 만나요.      ← 유튜브 자막 학습 흔적(발화에 없던 문장)
> ```
> Apple 전사문에서는 반복·창작이 0건이었다. 의료·상담처럼 **없는 말이 들어가면 안 되는 녹음**은 whisper를 그대로 믿으면 안 된다.

## 4. 항목별 판정

| 항목 | 승자 | 근거 |
|---|---|---|
| 속도 | **Apple** | 13배 (30분 → 8초 vs 104초) |
| 설치·유지비 | **Apple** | 무설치 vs 1.5GB 모델 + brew |
| 환각 안전성 | **Apple** | 반복 0건 vs 12줄 + 창작 문장 |
| 고유명사·제품명 | **whisper** | 사례 A 4/4 vs 0/4 |
| 문장부호·가독성 | **whisper** | 기본 제공 vs LLM 후처리 필요 |
| 대화체 구분 | **whisper** | 발화별 줄바꿈 vs 한 덩어리 |
| 내용 누락 | **whisper** | Apple이 25% 적게 담은 사례 |
| 프라이버시 | 무승부 | 둘 다 완전 로컬 |

## 5. 권장 운용

| 상황 | 엔진 |
|---|---|
| 산책 단상·일기 (기본) | **Apple** — 빠르고 환각 없음. 띄어쓰기 교정만 붙이면 충분 |
| 인물·제품·기관 이름이 중요 | **whisper** — `engine = "whispercpp"`로 임시 전환 후 처리 |
| 진료·상담·회의 (내용 보존) | **whisper** + 반복줄 육안 확인 (환각 문장 주의) |
| 배터리·속도 민감 (대량 배치) | **Apple** |

전환은 한 줄:

```bash
# config.toml → [asr] engine = "whispercpp"
.venv/bin/python main.py file "음성 002.m4a"     # 재처리 (reset 후)
```

> [!note] 전환 시 참고
> whisper는 이미 띄어쓰기가 정상이므로 `[postprocess].spacing_fix = false`로 두는 게 좋다(LLM 호출 절약). 단 파이프라인은 현재 엔진과 무관하게 교정을 시도하므로, 상시 whisper로 갈 경우 이 부분을 자동 스킵으로 바꾸는 게 좋다.
