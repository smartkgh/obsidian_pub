# LLM Wiki Research Template

AI 에이전트와 함께 **자료를 모아 정리·분석하고, 그 결과로 문서를 만드는** 프로젝트용 위키 템플릿이다.
원본 자료(`raw/`)를 넣으면 에이전트가 지식 페이지(`wiki/`)를 만들고, 요청에 따라 결과물(`outputs/`)을 만든다.

코드를 개발하는 프로젝트는 `llmwiki_template`을 쓴다.

## 이런 프로젝트에 쓴다
- 이력서·경력기술서: 기존 이력서, 업무 기록 → 지원처별 맞춤 이력서
- 조사 보고서: 기사, 논문, 공식 문서 → 비교 분석 보고서
- 문서 변환·요약: 회의록, 규정 문서 → 요약본, 다른 양식의 문서

## 새 프로젝트에 적용하기
1. 이 폴더를 통째로 복사하고 폴더 이름을 바꾼다.
   - **개인정보가 들어가는 프로젝트(이력서 등)는 공개될 수 있는 폴더(예: hugo_pub) 밖에 만든다.**
2. `AGENTS.md`의 **"0. 프로젝트 설정"** 을 채운다.
3. 자료를 `raw/sources/`에, 참고 양식을 `raw/assets/`에 넣는다.
4. 에이전트를 실행하고 "새 자료 정리해줘"라고 요청한다.

## 에이전트 호환
- 모든 규칙은 `AGENTS.md`에 있다. (Codex, Cursor 등은 자동으로 읽음)
- Claude Code: `CLAUDE.md`가 `@AGENTS.md` 한 줄로 같은 규칙을 불러온다.
- Gemini CLI: `.gemini/settings.json`이 `AGENTS.md`를 읽도록 설정되어 있다. 실행 후 `/memory show`로 확인.

## 자주 쓰는 요청 예시
| 하고 싶은 일 | 요청 예시 |
|---|---|
| 자료 정리 | "raw/sources에 새로 넣은 자료 정리해줘" |
| 질문·분석 | "A와 B 자료의 차이를 비교해줘" / "내 경력 중 데이터 분석 관련 경험만 모아줘" |
| 점검 | "위키 점검(lint)해줘" |
| 결과물 시작 | "A사 지원용 이력서 만들자. 양식은 raw/assets/이력서양식.docx" |
| 단계 진행 | "개요 승인. 초안 써줘" / "초안 검토해줘" / "최종본 DOCX로 만들어줘" |
| 결과물 고치기 | "경력 요약을 3줄로 줄여서 v2 만들어줘" |

## 이력서 프로젝트 예시
```
raw/sources/   기존이력서-2023.docx, 업무메모-2024.md, 성과평가-2025.pdf, A사-채용공고.md
raw/assets/    경력기술서-양식.docx
wiki/entities/ 회사-○○.md, 프로젝트-결제시스템.md   ← 기간, 역할, 성과(수치+근거)
wiki/concepts/ 기술-python.md, 역량-리더십.md       ← 어느 프로젝트에서 썼는지 링크
wiki/analysis/ A사-채용공고-적합도.md               ← 강조할 경험, 부족한 부분
outputs/2026-12-A사-이력서/  brief → outline → draft-v1 → review-v1 → final-v1.docx
```
경력 정리는 `wiki/`에 한 번 해 두고, 지원처마다 `outputs/`에 새 폴더로 맞춤 이력서를 만든다.
