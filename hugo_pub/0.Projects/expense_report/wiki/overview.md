# Overview

## 목적
교회 회계담당자가 영수증을 모아 손으로 작성하던 지출결의서를 앱으로 작성한다.
영수증 사진에서 일자와 금액을 자동으로 읽고, 원본 양식과 같은 DOCX/PDF를 만든다.

## 범위
- 포함: 영수증 인식(일자, 금액), 항목 선택, 적요/비고 입력, DOCX/PDF 출력, 영수증 증빙 첨부
- 실행 환경: 안드로이드 폰, 맥북 — 각각 로컬 전용, 외부 전송 없음
- 제외: 화면 서명, 기기 간 동기화, HWP 출력

## 현재 상태
- 현재 버전: v1 (draft)
- 외부 코드 경로: `~/my_projects/expense-report`
