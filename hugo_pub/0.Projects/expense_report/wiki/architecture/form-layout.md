# 결의서 레이아웃

> 원본 양식 파일을 받기 전까지 `raw/assets/지출결의서.jpeg`를 기준으로 한다.

## 원칙
- 칸의 위치와 크기를 `src/layout/`에 **한 번만** 정의하고 PDF와 DOCX가 같이 쓴다. 두 출력물의 모양이 일치한다.
- 용지: A4 세로, 결의서는 **항상 1페이지**.

## 1쪽: 결의서

| 영역 | 구성 | 채우는 값 |
|---|---|---|
| 제목 | "지 출 결 의 서" (밑줄, 가운데) | 고정 |
| 머리글 | 위원회명 : / 팀 명 : / 작성일 : 년 월 일 | 입력값 |
| 내역 표 머리 | ①일자, ②항목, 적 요, 금 액, 비 고 (열 너비 약 15/18/25/17/25%) | 고정 |
| 내역 표 본문 | **14줄** | 입력값, 빈 값은 빈칸 |
| 합계 줄 | "합 계" (①~적요 병합) + 금액 합계 | 자동 계산 |
| 송금처 | ③송금처 / 계좌번호 : / 예금주 : | **빈칸** |
| 서명·예산 | ④회계, ⑤팀장 (이름 + 서명 공간) / 부서총예산, 지출후잔액, 예산집행률 | 이름만 입력값, 나머지 **빈칸** |
| 회색 칸 | 제출일, 경유 사무처장, 이용주, 사역지원위원장 | **빈칸**, 원본처럼 회색 음영 |
| 작성요령 | 원본 문구 4줄 + 회색 칸 안내 | 고정 |
| 바닥 | 교회명 (왼쪽), "2023.9.1 개정" (오른쪽) | 고정 |

### 칸 값 표시 형식
- 일자: `11월 8일`
- 금액: `49,700원` (천 단위 쉼표 + 원)
- 적요, 비고: 칸 너비를 넘으면 글자 크기를 줄이고, 그래도 넘으면 2줄까지 줄바꿈

### 최대 줄 수 = 14
원본 이미지의 내역 표 높이와 손글씨 줄 간격을 기준으로, 1페이지에 작성요령까지 들어가는 최대값이다. (구현 후 출력물로 확인)

## 2쪽부터: 영수증 증빙
- 한 쪽에 **6장** (2열 × 3행)
- 각 칸 위에 `내역 N · 11월 8일 · 49,700원` 표시
- 사진은 칸에 맞게 비율 유지 축소, 파일 크기를 줄이기 위해 긴 변 약 1600px로 다시 저장
- 영수증이 없으면 증빙 페이지를 만들지 않는다
