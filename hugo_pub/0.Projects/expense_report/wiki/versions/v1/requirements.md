# v1 요구사항

## 목표

회계담당자가 손으로 쓰던 지출결의서를 앱으로 작성한다.
카드 영수증 사진을 올리면 일자와 금액이 자동으로 입력되고, 결과는 원본 양식(`raw/assets/지출결의서.jpeg`)과 같은 모양의 DOCX와 PDF로 나온다.
출력한 문서에 손으로 서명하고, 송금처 등 나머지 칸을 적어 상위 담당자에게 제출한다.

## 사용 흐름

1. 회계담당자가 카드 영수증 사진을 올린다. (여러 장)
2. 앱이 영수증마다 승인일자와 금액을 읽어 한 줄씩 채운다. 읽지 못한 칸은 비워 둔다.
3. 회계담당자가 줄마다 항목을 선택하고, 적요와 비고를 입력한다. 자동 입력값이 틀리면 고친다.
4. 위원회명, 팀명, 작성일, 서명란 이름을 입력한다.
5. DOCX 또는 PDF로 내보낸다. 결의서는 1페이지, 그 뒤 페이지에 영수증 이미지가 증빙으로 붙는다.
6. 인쇄해서 ④회계, ⑤팀장 칸에 서명하고 송금처를 적어 제출한다.

## 양식 구조 (원본: `raw/assets/지출결의서.jpeg`, 2023.9.1 개정판)

원본 양식 파일(HWP/DOCX)을 받기 전까지는 이 이미지를 기준으로 모양을 맞춘다.

| 영역 | 필드 | v1 처리 |
|---|---|---|
| 머리글 | 위원회명, 팀명, 작성일(년 월 일) | 사용자 입력 (작성일은 오늘 날짜 기본값) |
| 내역 표 | ①일자, ②항목, 적요, 금액, 비고 | 아래 REQ 참고 |
| 합계 | 금액 합계 | 자동 계산 |
| 송금처 | ③송금처(은행), 계좌번호, 예금주 | **비워 둠** — 출력 후 별도로 기입 |
| 서명란 | ④회계, ⑤팀장 | 이름만 입력 가능, 서명 칸은 비워 둠 |
| 예산 | 부서총예산, 지출후잔액, 예산집행률 | **비워 둠** — 출력 후 필요하면 수기 기입 |
| 회색 칸 | 제출일, 경유 사무처장, 사역지원위원장 등 | **비워 둠** (작성요령: 부서에서 기재하지 않음) |
| 하단 | 작성요령, 교회명, 개정일 | 원본 양식 그대로 고정 출력 |

## 요구사항

### 추가

| ID | 내용 | 우선순위 | 수용 기준 |
|---|---|---|---|
| REQ-001 | 영수증 이미지 업로드 (여러 장) | 높음 | 스마트폰 카메라 촬영 또는 사진첩/파일에서 선택 가능 |
| REQ-002 | 카드 영수증에서 승인일자 자동 인식 → ①일자 입력 | 높음 | 카드 영수증의 승인일자를 읽어 채움. 인식 실패 시 빈칸 |
| REQ-003 | 카드 영수증에서 금액 자동 인식 → 금액 입력 | 높음 | 카드 영수증의 합계(승인금액)를 읽어 채움. 인식 실패 시 빈칸 |
| REQ-004 | 자동 입력값 확인 및 수정 | 높음 | 모든 자동 입력값을 사용자가 고칠 수 있음. 영수증 이미지를 보며 확인 가능 |
| REQ-005 | ②항목을 선택 상자로 선택 | 높음 | 기본 목록: `야유회비`, `교사 월례회의`. 선택하지 않으면 출력물에서 빈칸 |
| REQ-006 | 적요, 비고 직접 입력 | 높음 | 줄마다 자유 입력 |
| REQ-007 | 영수증 없는 줄 직접 추가 | 중간 | 영수증 없이 일자/항목/적요/금액/비고를 손으로 입력 가능 |
| REQ-008 | 합계 자동 계산 | 높음 | 입력된 금액의 합계를 천 단위 쉼표와 "원"으로 표시. 빈 금액은 제외 |
| REQ-009 | 머리글과 서명란 이름 입력 | 높음 | 위원회명, 팀명, 작성일, ④회계/⑤팀장 이름 입력 가능. 비우면 출력물에서 빈칸 |
| REQ-010 | 결의서는 항상 1페이지 | 높음 | 내역 줄 수에 최대값을 두고, 최대값을 넘으면 줄 추가를 막고 안내 메시지를 보여 줌 |
| REQ-011 | 원본 양식과 같은 모양으로 DOCX 출력 | 높음 | A4 1페이지, 표 구성과 칸 위치가 원본 이미지와 같음. Word에서 열어 수정 가능 |
| REQ-012 | 원본 양식과 같은 모양으로 PDF 출력 | 높음 | A4, 한글 깨짐 없음, 그대로 인쇄 가능 |
| REQ-013 | 결의서 뒤 페이지에 영수증 이미지 증빙 첨부 | 높음 | 한 쪽에 6장, 영수증마다 해당 줄 번호/일자/금액과 함께 배치 (DOCX, PDF 모두) |
| REQ-014 | 로컬 전용 동작 | 높음 | 영수증 이미지와 입력 내용이 외부 서버로 전송되지 않음. 인터넷 없이 동작 |
| REQ-015 | 안드로이드 스마트폰에서 사용 | 높음 | 안드로이드 폰에서 단독으로 REQ-001~013 기능 사용 가능 |
| REQ-016 | 맥북에서 사용 | 높음 | 맥북에서 단독으로 REQ-001~013 기능 사용 가능 (폰과 데이터 연동 없음) |
| REQ-017 | 작성 중인 내용 기기에 저장 | 중간 | 앱을 닫았다 열어도 작성 중인 결의서가 남아 있음 |

## 범위에서 제외 (v1)

- 화면 서명 (출력 후 손으로 서명)
- 송금처, 예산 칸 입력 (출력 후 별도 기입)
- 항목 목록 편집 화면 (v1은 기본 2개 고정)
- 간이영수증(손글씨), 온라인 결제 내역 인식
- 2페이지 이상 결의서
- 폰과 맥북 사이 데이터 동기화, 결의서 이력 관리
- HWP 출력
