# v1 요구사항

## 목표

회계담당자가 손으로 쓰던 지출결의서를 앱으로 작성한다.
영수증 사진을 올리면 일자와 금액이 자동으로 입력되고, 결과는 기존 종이 양식과 같은 모양의 DOCX와 PDF로 나온다.
출력한 문서에 팀장이 손으로 서명한 뒤 상위 담당자에게 제출한다.

## 사용 흐름

1. 회계담당자가 영수증 사진을 올린다. (여러 장)
2. 앱이 영수증마다 승인일자와 금액을 읽어 한 줄씩 채운다.
3. 회계담당자가 줄마다 항목을 선택하고, 적요와 비고를 입력한다. 자동 입력값이 틀리면 고친다.
4. 위원회명, 팀명, 송금처 등 머리글/바닥글 정보를 입력한다.
5. DOCX 또는 PDF로 내보낸다. 결의서 뒤 페이지에 영수증 이미지가 증빙으로 붙는다.
6. 인쇄해서 ④회계, ⑤팀장 칸에 손으로 서명하고 제출한다.

## 양식 구조 (원본: `raw/assets/지출결의서.jpeg`, 2023.9.1 개정판)

| 영역 | 필드 | 입력 방식 |
|---|---|---|
| 머리글 | 위원회명, 팀명, 작성일(년 월 일) | 사용자 입력 (작성일은 오늘 날짜 기본값) |
| 내역 표 | ①일자, ②항목, 적요, 금액, 비고 | 아래 REQ 참고 |
| 합계 | 금액 합계 | 자동 계산 |
| 송금처 | ③송금처(은행), 계좌번호, 예금주 | 사용자 입력 |
| 서명란 | ④회계, ⑤팀장 | 이름만 입력, 서명 칸은 비워 둠 |
| 예산 | 부서총예산, 지출후잔액, 예산집행률 | 사용자 입력 (잔액, 집행률 자동 계산 여부는 열린 질문) |
| 회색 칸 | 제출일, 경유 사무처장, 사역지원위원장 등 | **비워 둠** (작성요령: 부서에서 기재하지 않음) |
| 하단 | 작성요령, 교회명, 개정일 | 원본 양식 그대로 고정 출력 |

## 범위에서 제외 (v1)

- 화면 서명 (출력 후 손으로 서명)
- 폰과 맥북 사이 데이터 동기화
- 예산신청서 연동, 여러 결의서 이력 관리
- HWP 출력

## 열린 질문

1. **②항목 목록**: 예산신청서에 있는 항목 전체 목록이 필요합니다. 원본에는 "야유회비(?)", "교사 월례회의"가 보입니다.
2. **내역 줄 수**: 한 장에 들어가는 최대 줄 수를 넘으면 2페이지로 넘길지, 결의서를 나눌지.
3. **예산 칸**: 지출후잔액(= 부서총예산 − 이번 합계)과 예산집행률을 자동 계산할지, 직접 입력할지. 이전까지 쓴 금액을 반영해야 하는지.
4. **송금처**: 결의서 한 장의 송금처가 보통 한 곳인지, 원본처럼 줄마다 다른 경우가 많은지.
5. **영수증 종류**: 주로 카드 영수증인지, 간이영수증(손글씨)이나 온라인 결제 내역 캡처도 있는지. 손글씨 영수증은 자동 인식이 어렵습니다.
6. **원본 양식 파일**: 지출결의서 원본 HWP/DOCX 파일이 있으면 출력 모양을 더 정확하게 맞출 수 있습니다.
