# v1 결과 보고

## 요약
카드 영수증 사진에서 일자와 금액을 자동으로 읽어, 교회 지출결의서 양식과 같은 모양의 PDF·DOCX를 만드는 **로컬 전용 웹앱**을 만들었다.
**맥북에서는 실제 영수증 2장의 일자·금액을 모두 맞혔다** (Apple Vision 로컬 도우미). 결의서 1쪽과 영수증 증빙 페이지(6장/쪽)가 정상 출력된다.
**안드로이드 폰은 검증하지 못했고**, 폰 단독 사용 시 인식 엔진(Tesseract.js)은 실제 영수증을 거의 읽지 못한다(맥 기준 0/2).
사용자 요청(2026-11-26)으로 수동·폰 검증 8개 항목을 **미실행 상태로 두고 v1을 마무리**한다.

- 코드: `~/my_projects/expense-report` (git 태그 `v1.0`)
- 맥 실행: `npm run serve` → 크롬 `http://localhost:8080`
