# 바이브컴퍼니 (구, 다음소프트)

## 개요
강기훈이 2001년 3월부터 2007년 7월까지 과장 직급으로 재직하며 자연어처리연구소·솔루션부서·SI부서를 거쳐 대화형 에이전트 서비스, CRM 솔루션, 대규모 SI 프로젝트를 수행한 첫 정규직 회사다. ([[overview]] 규칙에 따라 `바이브컴퍼니 (구, 다음소프트)`로 병기)

## 주요 사실·활동
- **자연어처리/대화형 서비스 (2004.05 ~ 2007.01)**: 다음아이(대화형 검색엔진, PL), 한국어/불어/리노베이션 아우(대화형 미니홈피 SNS), MO 모바일 대화(PL), MSN 아이버디(광고연동), Ever2-뮤즈 로봇 대화연동(PM, 코엑스 로봇전시회 출품), KT 친친(소봇), Kaist 온톨로지 기반 대화에이전트(PL). ([[my-이력서-상세경력기술서-자기소개서]], [[my-job-history-skplanet-입사설명용]])
- **CRM/VOC 솔루션 (2001.05 ~ 2007.06)**: 삼성캐피탈·011-estation·KT·Wizgate·SKT 011/017 통합·SKT VOC 리뉴얼 사이버 상담시스템(ERMS), KT 스팸민원 처리, KT 고객니즈(S&R) 관리 시스템(PL, Analyzer 연동). ([[my-이력서-상세경력기술서-자기소개서]], [[my-job-history-skplanet-입사설명용]])
- **대규모 SI (2003.01 ~ 2004.04)**: WorkNet 사이트 전체 리뉴얼(PL, 500여 개 DB 테이블 분석/설계, XML 기반 SQL 프레임워크 자체 개발), 코트라 사이버 전시회(PL), SK Rainbow 포인트 시스템(MQ 데몬 연동), 다음 사전 검색 서비스(백과사전/영어/영한사전). ([[my-이력서-상세경력기술서-자기소개서]], [[my-job-history-skplanet-입사설명용]])
