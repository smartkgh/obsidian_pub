# 양식: 경력기술서 - 혼합형 (서치라이트)

## 원본
- 파일: `raw/assets/경력기술서 양식 - 혼합형 (서치라이트)의 사본.docx`

- 작성일/기간: 미상
- 수집일: 2026-11-26

## 요약
회사별 연대기(최신순) 구조 안에 **프로젝트 단위 카드(`PROJECT 01`, `PROJECT 02` …)**를 중첩한 **혼합형** 경력기술서 양식이다. 각 프로젝트마다 `프로젝트 기간`, `주요 성과`(KPI 한 줄), `역할`(번호 목록 1~3), `기술·툴`(불릿 목록)을 구조화해 기술 역량과 프로젝트 단위 기여도를 상세히 보여주기에 적합하다.

## 핵심 내용
- **상단 헤더**: `경 력 기 술 서`, `총 경력 [OO년 OO개월]`
- **회사 헤더 바 테이블**: `[회사명] [부서명 / 직책(직급)]` | `yyyy.mm – yyyy.mm · O년 O개월`
- **프로젝트 상세 테이블** (`PROJECT 01 [프로젝트명]`, `PROJECT 02 [프로젝트명]` ...):
  - `프로젝트 기간`: `yyyy.mm – yyyy.mm`
  - `주요 성과`: KPI 중심 핵심 성과를 수치와 함께 한 줄로 요약
  - `역할`: 번호 매김(`1.`, `2.`, `3.`)으로 핵심 액션과 성과 요약
  - `기술·툴`: `-` 불릿으로 실제 사용한 도구·언어·시스템과 활용 맥락 기술
- **주의사항**: 원본 1행에 Google Docs 안내 배너(`✏️ 이 파일은 보기 전용입니다...`)가 포함되어 있으므로 최종본 작성 시 제거해야 함.
