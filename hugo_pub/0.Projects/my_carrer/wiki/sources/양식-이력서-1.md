# 양식: 이력서양식1 (잡코리아형 DOCX)

## 원본
- 파일: `raw/assets/이력서양식1.docx`
- 작성자/출처: 잡코리아 기본 이력서 양식 (추정, 예시 이메일 `@jobkorea.co.kr`)
- 작성일/기간: 미상
- 수집일: 2026-11-26

## 요약
인적사항, 학력사항, 경력사항, 수상내역, 어학, 교육/연수, 병역, 자기소개서로 구성된 표준 국문 이력서 DOCX 양식이다. 상단 좌측에 증명사진 영역(`word/media/image1.png`)이 포함되어 있다.

## 핵심 내용
- **기본 정보 테이블**: 이름(한글/영문/한자), 생년월일, 전화번호, 휴대전화, 이메일, 홈페이지, 주소(민번 자리표시 포함).
- **학력사항**: 학력 요약(예: 대학교 졸업) + 입학~졸업 연월 + 학교명·전공·졸업여부.
- **경력사항**: 총 경력 기간 + 근무기간(`yyyy.mm ~ yyyy.mm`) + 회사명·부서·직급 / `[연봉]` / `[주요 수행 프로젝트]` (1~3번 항목별 담당 업무 및 세부 내용).
- **수상내역 / 어학 / 교육·연수 / 병역**: 각 해당 항목 행(해당 없으면 생략 또는 조정 가능).
- **자기소개서** (별도 테이블): 소제목 + 본문 블록 반복 구조(6개 소제목 슬롯).
