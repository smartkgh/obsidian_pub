# SK 플래닛 입사 시 Job History 설명 자료

## 원본
- 파일: `raw/assets/my_Job History_강기훈_skPlanet입사시 설명용.pptx`
- 작성자/출처: 강기훈 본인 작성 (SK 플래닛 입사 면접/설명용 발표자료)
- 작성일/기간: 2013년 말 추정 (개발 경력 12년 6개월 표기, 최신 프로젝트 114 전국전화 Mobile Service)
- 수집일: 2026-11-26

## 요약
2013년 SK 플래닛 입사 시 본인의 12년 6개월 개발 경력을 `Service`, `Solution`, `SI`, `Android` 4개 축으로 분류해 기술 스택과 핵심 성과를 요약한 17슬라이드 발표 자료다. 기존 이력서(`.doc`)에 없던 구체적 데이터 규모(500만 건 전화 데이터, 4,000만 건 지번 데이터, 워크넷 500여 개 DB 테이블)와 시스템 아키텍처 포인트가 포함되어 있다.

## 핵심 내용
- 표지 (slide 1): 생년월일 1973.10.30, 경기대 전자계산학과, 개발 경력 12년 6개월.
- **Service 영역** (slides 2~7):
  - 114 전국전화 Mobile Service: 500만 건 전화 Data, 4,000만 건 지번 Data 관리, Redis 지오코딩 연동, Bootstrap CMS UI, 시스템 내재화(Mysql/Linux, Java/Jsp/JS, Spring/Mybatis/Tiles/Bootstrap).
  - Online Marketing Service (와이즈넛): 개발 팀장 및 PL. Memcached 활용 광고 Delivery Module 개발, Overture/Google Adwords Open API 연동, Naver/Daum 크롤링 수집, Adcare(광고주 통합 관리툴)·AdPlus(CPC Network Display)·Keyword 광고·Overture CM Partner(Context Match) 수행.
  - 대화 Agent Service (다음소프트): 각 프로젝트 개발 PL. 대화 Agent CMS 및 대화 추론 모듈 개발, 영어/불어/사투리 지원, 아우닷컴(대화 홈피 SNS), 다음아이(대화형 검색), Ever2 뮤즈/KT 소봇(친친), MO Message Receiver Daemon 개발.
- **Solution 영역** (slides 8~10):
  - 011-estation Cyber 상담센터 구축: Email/문의 게시판 자동응답 Solution(ERMS), Legacy 연동 및 Customizing, DHTML Rich Web Application CMS.
  - Analyzer(고객 VOC 및 Needs 분석 Solution), Online Network 광고 Solution.
- **SI 영역** (slides 11~13):
  - 워크넷 사이트 구축: Java 기반 전체 Renewal, 500여 개 DB Table 분석/설계, XML 기반 SQL Management Framework 자체 개발, 기업회원 구인 페이지.
  - 기타 SI: 다음 사전 검색 서비스(백과사전 통합 Contents Maker Tool), SKT Rainbow 포인트 서비스(Message Queue 연동), KOTRA 사이버 전시회 사이트.
- **Android 영역** (slides 14~16):
  - Pudding.To Android App: 개발 PL로 전체 System 설계, ThreadPooling 기반 ImageDownloader/Caching Module 개발, TimeLine Custom UI, Webpage Protocol용 Custom WebView Module, 5개국어 Global Photo SNS.
  - 기타 Android Apps: Pudding Camera(1,500만 다운로드, InApp Module), 114전국전화 App(GCM Push Service), 모가조아 App(Launcher Home 같은 Custom UI).
