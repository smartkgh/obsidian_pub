# 가이드: 경력기술서 작성 예시

## 원본
- 파일: `raw/assets/경력기술서작성예시.xlsx.pdf`
- 작성자/출처: 경력기술서 작성 예시 PDF (2페이지)
- 작성일/기간: 미상
- 수집일: 2026-11-26

## 요약
`프로젝트명/업무명`, `기간`, `성과`, `역할`, `기술` 5개 행으로 구성된 표 형식의 경력기술서 모범 예시(MD, 품질관리, 재무회계 3개 직무 사례)다. 모든 역할 항목이 `행동 + 정량 결과` 구조의 짧은 개조식으로 작성된 점이 특징이다.

## 핵심 내용
- **표 구조**: `프로젝트명/업무명` | `기간` | `성과` | `역할` (`1)`~`5)` 번호 목록) | `기술` (`1)` 도구/툴, `2)` 도메인/프로세스 이해).
- **문장 작성 패턴**:
  - 프로젝트명/업무명 자체에도 핵심 성과를 한 줄로 요약 포함.
  - `역할` 각 줄을 `"무엇을 분석/개선/구축해 → 어떤 수치/결과를 달성"` 형태로 압축.
  - `기술`란에는 구체적 툴(Jira, Data Studio, Slack, ERP 등)과 도메인 이해도(프로세스·법률·품질규격 등)를 병기.
