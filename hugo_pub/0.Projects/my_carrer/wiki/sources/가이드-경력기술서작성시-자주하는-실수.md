# 가이드: 경력기술서 작성 시 자주하는 실수 4가지

## 원본
- 파일: `raw/assets/경력기술서작성시 자주하는 실수.pdf`
- 작성자/출처: 경력기술서 작성 가이드 PDF (5페이지)
- 작성일/기간: 미상
- 수집일: 2026-11-26

## 요약
경력기술서 작성 시 흔히 범하는 4가지 실수(분량·가짓수 부적절, 일관성 부족, 서술형 작성, 전문용어 남발)를 사례와 함께 짚어주는 5페이지 가이드 문서다. 총 경력의 1/2 이상을 다루되 지원 직무 중심으로 일관성 있게 최신순 정렬하고, 개조식(요약·압축)으로 성과 중심 액션을 작성할 것을 권장한다.

## 핵심 내용
- **Case 1. 가짓수가 너무 적거나 과도한 경력기술서 (pp.1~2)**:
  - 경력 제시는 **총 경력 기간의 1/2 이상** 작성하는 것이 좋음.
  - 잘 제시한 예시 포맷: `프로젝트/업무명` / `기간` / `성과` / `역할`(번호 목록 1~4) / `기술`.
- **Case 2. 일관성이 떨어지는 경력기술서 (p.3)**:
  - 지원 직무·회사와 무관한 경력은 과감히 제거.
  - 일상적 To-do list를 모두 나열하지 말고 **성과에 영향을 준 핵심 액션 위주**로 간략 요약.
  - **기간은 일관성 있게 정렬**(오름차순/내림차순 혼재 금지, 지원 직무와 직결되는 최근 성과부터 제시 권장).
- **Case 3. 서술형으로 작성한 경력기술서 (p.4)**:
  - 줄글 서술형 대신 **개조식(요약과 압축)**을 사용해야 짧은 문서로 전체를 이해시킬 수 있음.
- **Case 4. 전문용어로 구성된 경력기술서 (p.5)**:
  - 해당 도메인 전문용어 없이는 평가할 수 없게 쓰지 말고, 누구나 이해할 수 있는 쉬운 말과 비즈니스·성과 관점 설명을 병행.
