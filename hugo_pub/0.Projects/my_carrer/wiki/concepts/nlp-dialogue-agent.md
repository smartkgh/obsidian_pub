# 자연어처리 및 대화형 에이전트 개발

## 정의
2004~2007년 [[바이브컴퍼니]] (구, 다음소프트) 자연어처리연구소에서 수행한 상황 대화 추론 모듈, 다국어 대화형 에이전트, 메신저/모바일/로봇 연동 대화 서비스 개발 영역이다.

## 설명
- 대화 Agent CMS 및 상황 대화 추론 모듈 개발을 기반으로 다음아이(대화형 검색), 한국어·불어·영어 아우(세계 최초 대화형 미니홈피 SNS), MO 모바일 대화(이통 3사 문자 연동 Daemon), MSN 아이버디(대화 키워드 광고 연동), Ever2-뮤즈 로봇(음성/모션 인식 연동), KT 친친(소봇), KAIST 온톨로지 기반 대화 에이전트를 개발·PL/PM으로 수행했다.
