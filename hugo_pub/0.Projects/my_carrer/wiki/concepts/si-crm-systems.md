# 대규모 SI·백엔드 및 CRM 솔루션 구축

## 정의
[[바이브컴퍼니]] (구, 다음소프트) 시절의 대규모 웹 SI·고객 VOC/사이버상담 CRM 솔루션(ERMS/Analyzer)부터 [[kt알파]] 시절의 114 전국전화 POI/광고 CMS 및 Open API 서버 개발까지 이어지는 웹·백엔드·데이터베이스 아키텍처 역량이다.

## 설명
- **CRM/VOC 솔루션 (2001~2007)**: 삼성캐피탈·SKT(011-estation, 011/017 통합, VOC 리뉴얼)·KT(사이버상담, 스팸민원, 고객니즈 S&R)·위즈게이트 사이버상담센터(ERMS·Analyzer 연동) 구축.
- **대규모 SI (2003~2004)**: 워크넷 전체 리뉴얼(500여 개 DB 테이블 분석/설계, XML 기반 SQL 프레임워크 자체 개발), 코트라 사이버 전시회, SK Rainbow 포인트(MQ 데몬 연동), 다음 사전 검색 서비스.
- **대용량 백엔드/API (2013)**: 114 전국전화 POI(전화 500만 건, 지번 4,000만 건)·광고 CMS 내재화, Redis 지오코딩, Open API 서비스 구축.
