# 기존(안티그래비티) 초안과 다르게 한 점
- 경력기술서 2종 상단에 **[경력 요약] + 핵심 역량 3축**을 넣었다 (STAR 가이드 권장).
- SK 플래닛 PROJECT를 **최신순**(AI → 광고·리워드 → 단말 → 금융·DevOps → 보안 → O2O)으로 다시 정렬하고, O2O 기간을 업무히스토리 근거에 맞춰 2014.07 – 2018.12로 바꿨다.
- 근거가 없는 기간·역할은 지어내지 않고 [확인 필요]로 남겼다.
- 사내 용어(P.AD, OWP, TR 등)를 일반 표현으로 풀었다.
- 주민등록번호는 초안에 쓰지 않았다.
